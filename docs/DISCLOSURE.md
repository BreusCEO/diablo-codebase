# Models, data and components used

Disclosure for the hackathon (rule 04). Versions are exactly those in `package.json`, `site/package.json` and `engine/requirements.txt`.

## Models

| Where | Model | Status |
|---|---|---|
| Demo workspace (app.diablo.pnoia.dev) | none: the demo agent is rule-based (`src/lib/data/mock/agent.ts`) and runs are simulated by a seeded simulator | live |
| Live engine (`src/lib/live/`) | Google Gemini via the Gemini API, or Z.ai GLM via its OpenAI-compatible API, chosen by environment variables | in the repo; runs only when a model key is configured, otherwise it is disabled and says so |
| Python engine (`engine/`) | Google Gemini via `google-genai`, default `gemini-3.1-pro-preview` | in the repo; tests use a mocked client |
| Planned reasoning model | GLM-5.3 (Z.ai) | planned |
| Development | the team built the project with AI coding assistance (Claude Code) | used during development |

No model is trained or fine-tuned. No model output is ever used as a number: every statistic is computed by code (`src/lib/stats.ts`).

## Data

- Demo investigations: hand-written fixtures (`src/lib/data/mock/catalog.ts`, `fixtures.ts`) plus a seeded run simulator (`simulate.ts`). Labelled "Demo data" in the app.
- Live engine: arithmetic items generated by code with exact answers (seeded).
- Benchmark: 45,000 simulated, seeded scenarios (`src/lib/bench/`, `docs/BENCHMARK.md`).
- No personal data, customer data or scraped data. Google sign-in stores only name and email in a signed cookie; there is no database.
